# ⚡ OptiCore Pro

OptiCore Pro is a futuristic cyber-style system optimization simulator made using HTML, CSS, and JavaScript. It gives the feeling of using a high-tech system cleaner with glowing neon effects, animated system stats, and AI-based suggestions.

This project is only for simulation and design purposes. It does not actually clean files, boost performance, or optimize your real device.

---

## 🚀 Live Demo

🔗 Demo Link: https://mayankbiswasgame-debug.github.io/OptiCore-Pro/

## ✨ Features

* Futuristic neon cyber UI
* Simulated CPU, RAM, and Disk usage
* Boost System button to reduce usage values
* Clean System button to simulate removing temporary files
* AI Analyze feature for smart suggestions
* Activity log to show recent actions
* Smooth hover effects and glowing buttons
* Clean and simple dashboard layout

---

## 🖥️ About the Project

OptiCore Pro was created as a fun frontend project that looks like a real system optimizer dashboard. The idea was to build something visually attractive and interactive using only basic web technologies.

Users can click different buttons to simulate actions like boosting performance, cleaning the system, and analyzing device health. Every action updates the stats, AI assistant, and activity log in real time.

## ⚙️ How to Use

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser

No installation, setup, or external libraries are needed.

---

## 📌 Main Functions

### Boost System

Reduces CPU, RAM, and Disk values to simulate better performance.

### Clean System

Shows a message that temporary files and cache have been cleared.

### AI Analyze

Provides simple suggestions based on the current simulated system status.
